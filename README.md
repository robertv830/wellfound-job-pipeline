# Wellfound Talent Market Pipeline

An automated data pipeline built with Python, Apify, and Pandas that extracts tech job listings, structures unstructured requisition data, and exports clean datasets for recruitment analytics and job tracking.

## Features
- **Automated Scraping:** Leverages Apify actors to pull real-time job requisitions safely.
- **Data Transformation:** Uses Pandas to process, clean, and structure raw JSON into tabular data.
- **Pipeline Ready:** Instantly exports structured datasets to CSV for tracking dashboards and spreadsheets.

## Tech Stack
- Python
- Apify API (`apify-client`)
- Pandas
- python-dotenv
